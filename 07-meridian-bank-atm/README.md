# Meridian Bank ATM

A console-based Java ATM simulation demonstrating encapsulation, custom exceptions, validation, and file I/O.

## Client Brief

Meridian Bank wants a simple ATM application that allows customers to:

* Check their account balance.
* Deposit money.
* Withdraw money.
* View account details.
* Reject invalid transactions.
* Record every transaction attempt in a log file.

The application should remain stable when users enter invalid data.
