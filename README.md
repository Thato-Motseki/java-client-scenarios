# Java Client Scenarios

A progressive collection of 10 scenario-based Java applications built around small business client briefs.

The projects are designed to develop practical Java programming skills progressively, starting with basic programming logic and gradually introducing object-oriented programming, collections, exception handling, file I/O, GUI development, serialization, and database connectivity.

## Projects

| #  | Client                 | Project                   | Main Concepts                                |
| -- | ---------------------- | ------------------------- | -------------------------------------------- |
| 01 | Corner Bakery          | Order Total Calculator    | Variables, input, conditionals, arithmetic   |
| 02 | FitZone Gym            | Membership Fee Calculator | Conditionals, loops, methods                 |
| 03 | Green City High School | Grade Report Generator    | Arrays, loops, averages                      |
| 04 | QuickMart Retail       | Stock Level Checker       | Classes, objects, ArrayList                  |
| 05 | DriveEasy Car Rental   | Rental Cost Estimator     | Enums, validation, exceptions                |
| 06 | GreenCity Library      | Book Lending System       | Abstract classes, inheritance, interfaces    |
| 07 | Meridian Bank          | Mini ATM Simulator        | Encapsulation, exceptions, file I/O          |
| 08 | StarNight Events       | Ticket Booking Desk       | Java Swing, GUI, event handling              |
| 09 | SwiftShip Logistics    | Package Tracking Records  | Serialization, collections, file persistence |
| 10 | Bramble & Co.          | Point-of-Sale System      | Swing, JDBC, MySQL, transactions             |

## Purpose

These projects are practice applications based on client-style requirements rather than isolated programming exercises.

The goal is to practise translating a client's requirements into:

* Functional requirements
* Program logic
* Classes and objects
* Appropriate data structures
* Validation rules
* Error handling
* User interfaces
* Persistent data
